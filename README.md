# Notepad

A simple and lightweight Notepad application built with Kivy, providing a clean interface for creating, editing, and saving text files.

## ✨ Features

* Create and edit text files
* Open existing documents
* Save notes locally
* User-friendly interface
* Cross-platform support with Kivy

## 🛠 Built With

* Python
* Kivy

## 📂 About

This project demonstrates how to build a basic text editor using the Kivy framework, focusing on simplicity, usability, and cross-platform compatibility.

## 🚀 Run

```bash
python main.py
```
